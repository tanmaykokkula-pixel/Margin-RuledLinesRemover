# Margin-RuledLinesRemover
This program aims to remove the blue and red lines from pictures of notebook paper. The MVP should have the ability to intake an image file, replace the color of the margin and rule lines, and then output an image without those lines. Later on, I hope to be able to include features that will match the edited colors to whatever color the base page is, so if it's not a white color, this program can still work. I also hope to find a way to include other paper formats like graphing paper or isographic paper as they will surely bring their own difficulties with differing line colors and thicknesses. I also plan on being able to change the background color entirely as necessary.

Tech stack:
- Java (JDK 17)
- Intellij IDE
- Image Handling
