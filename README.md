# Margin-RuledLinesRemover

This program aims to remove the blue and red lines from pictures of notebook paper. 

## The Problem

I like to sketch and doodle a lot but I only have notebook paper to draw on. Whenever I take pictures of my sketches, the blue lines and red margin line can be very annoying and feels like it could ruin the tone or confuse the design of whatever it is I'm drawing.

## How It Works

The MVP should have the ability to intake an image file, replace the color of the margin and rule lines, and then output an image without those lines. Later on, I hope to be able to include features that will match the edited colors to the 'background' white color of the page.
